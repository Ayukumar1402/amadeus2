**When to use this:** the customer already has a ticketed booking and wants to change a flight,
date, or routing. This covers both airline-initiated schedule changes and voluntary customer
changes, which usually carry a fare difference and/or change fee.

:::tip Draft content — verify before relying on it in production
Reissue rules are the most airline-specific part of this whole knowledge base — fare rules,
penalty amounts, and even the exact reissue command can differ by carrier and fare basis. Treat
the flow below as the general shape, and add airline-specific notes via a pull request if you
handle a carrier with unusual rules.
:::

## The flow

```mermaid
flowchart TD
    A[Retrieve the ticketed PNR<br/><code>RT</code>] --> B[Pull up the original ticket<br/><code>RTT</code>]
    B --> C[Make the itinerary change<br/>cancel old segment, sell new]
    C --> D[Reprice with exchange logic<br/><code>FXP/R,U</code>]
    D --> E{Fare difference<br/>+ change fee owed?}
    E -->|Yes| F[Collect additional payment<br/><code>FP</code>]
    E -->|No — waived, e.g. schedule change| G[Note waiver reason in remarks<br/><code>RM</code>]
    F --> H[Reissue the ticket<br/><code>TTP/ETICKET</code>]
    G --> H
    H --> I{New ticket number<br/>confirmed?}
    I -->|Yes| J[Read new itinerary + any residual value to customer]
    I -->|No| D
```

## Exchange with Amadeus GEVR (ATC)

Use the GEVR Shopper script when the ticket is ATC-eligible — Amadeus prices and guarantees the
fare automatically, which is faster and lower-risk than a manual reprice.

:::tip Before you launch GEVR
1. Coupon status must be **Open (O)** or **Airport Control (A)**. If it's **Check-in (CKIN)**,
   go to *Flight | Change | Change flight with status CKIN or C* first to see if it can be
   reopened.
2. Run the **Eligibility checker**. "Yes" means changes are permitted and the fare is guaranteed —
   continue. "Check Fare rules" means the script can't determine eligibility — for Pre-travel/FTC
   use the GEVR **Manual** flow instead; for a partial ticket use **Informative Pricing** outside
   GEVR.
3. **SWA WGA (Basic) fares:** check mini rules first. For tickets issued on/after May 28, WGA
   change eligibility only covers Credit redemptions, not Voluntary Change.
:::

```mermaid
flowchart TD
    A[Launch GEVR Shopper] --> B{Coupon status<br/>O or A?}
    B -->|CKIN| B2[Try to reopen via<br/>Change flight with status CKIN/C]
    B -->|O or A| C{Eligibility checker}
    C -->|No| Z[Exit — read fare rules for cancel options]
    C -->|Check fare rules| C2[Use GEVR Manual or<br/>Informative Pricing instead]
    C -->|Yes, guaranteed| D[Select Exchange]
    D --> E{Ticket validity<br/>within 1 year?}
    E -->|Flagged red| E2[Review fare rules for validity]
    E -->|OK| F[Select flights to modify: Change / Keep / Remove]
    F --> G[Set Fare Types — keep Public + Private selected<br/>WN: Economy cabin, Same fare family]
    G --> H[Review availability — quote Add Collect column only]
    H --> I{Traveler agrees to proceed?}
    I -->|No| Z2[Exit GEVR, delete new flights, RF;ER to save]
    I -->|Yes| J[Select flight, click Book]
    J --> K[Select Price → review new segments]
    K --> L[Click OK — do not edit, this reconfirms price]
    L --> M[Add Form of Payment — Published card / Merchant cash / EVC card]
    M --> N{Traveler accepts summary?}
    N -->|No| Z3[Exit GEVR — IR, delete new flights, RF;ER]
    N -->|Yes| O[I accept — charges card / removes old segments]
    O --> P[Queue place the PNR]
    P --> Q{Residual value present?}
    Q -->|Yes, remarks + FO *RV both present| R[Advise traveler of residual T&Cs, send email]
    Q -->|No| S[Document in OneDesk / Voyager Classic]
    R --> S
```

:::info Residual value — only quote if both fields are present
Check the remarks field for the EVR script\u2019s residual notes **and** display the FO line for a
`*RV` field. Both must be present for the residual to apply. If only one shows, don\u2019t quote a
residual to the traveler. When it does apply: no change fee to use it, it\u2019s non-transferable
(same passenger only), and — absent a specific fare-rule validity period — assume it must be
booked and used within 1 year of creation.
:::

## Exchange a flight outside GEVR (ATC) — infant fare family bookings

Use this manual ATC flow only when the booking has an infant traveler that needs fare family
qualifiers — GEVR doesn't handle this case.

```mermaid
flowchart TD
    A[Confirm FOP — check for virtual card<br/>OneDesk / Voyager] --> B[Retrieve PNR, emulate to ticketing OID<br/><code>RT</code>]
    B --> C[Confirm all segments HK<br/><code>RTI</code> / <code>RTA</code>]
    C --> D[Check UDID*75 for virtual card / FLEXMOR<br/><code>RTR</code>]
    D --> E[Display fare elements, confirm Office ID/IATA<br/><code>RTF</code>]
    E --> F[Run Mini Rules SmartFlow]
    F --> G{All passengers exchanging?}
    G -->|No| G2[Divide the PNR first]
    G -->|Yes| H[Identify fare family via TTH, look for FFC]
    H --> I[Search + sell new flights, same COS<br/>One Script Smart Flow]
    I --> J[Save changes<br/><code>RF</code> / <code>ER</code>]
    J --> K{Airline record<br/>locator received?<br/><code>IR</code> / <code>RL</code>}
    K -->|No| K2[Cancel + rebook same flights, re-save]
    K -->|Yes| L[Delete existing TST<br/><code>TTE/ALL</code>]
    L --> M[Reprice with ATC<br/><code>FXQ</code> as booked / <code>FXO</code> cheapest]
    M --> N{ATC error?}
    N -->|Yes| N2[Check entry, refer to ATC error table]
    N -->|No| O[MD one page — review add collect, residual, fare family, baggage]
    O --> P{Cabin or baggage downgraded?}
    P -->|Traveler declines| P2[IR, delete new flights, RF;ER]
    P -->|Traveler agrees| Q[Add remarks noting agreement]
    Q --> R{Add collect owed?}
    R -->|Yes| S[Authorize card / charge Voyager, update FOP]
    R -->|No| T[Update FOP — no auth needed]
    S --> U[Cancel unwanted segments<br/><code>XE</code>]
    T --> U
    U --> V[Add manual remarks<br/><code>RMA/</code>]
    V --> W[Save changes<br/><code>RF</code> / <code>ER</code>]
    W --> X[Add TSA info — Auto Recapture SFPD SmartFlow]
    X --> Y[Run EX_R SmartFlow — queue to CAT]
    Y --> AA[Document in OneDesk / Voyager Classic]
```
